# 进阶功能与配置

基础部署仍只需 IP＋端口。下列 SMTP、S3 和 OnlyOffice 都是可选服务，未配置时不会把文件发送到第三方在线预览网站。

## 文件操作与预览

在“我的文件”勾选项目后，可复制、剪切，再进入目标目录粘贴。支持 Ctrl/Cmd+C、X、V、A；输入框和弹窗内不拦截快捷键。复制包含目录结构、当前文件及标签，不复制历史版本和分享链接；同一真实对象可复用，但每个文件副本分别占用逻辑配额。单次最多 100 个入口、10000 个文件与目录。

上传重名策略可选择“覆盖并保留历史”：条目 ID 不变，原内容计入历史与配额。最多 20 个历史版本，目标已被修改时返回冲突，不悄悄覆盖新内容。

Markdown 支持数学公式、常用语言代码高亮、表格和相对图片/附件；外部图片不自动加载，脚本与危险 HTML 会清理。相对附件必须仍在本人空间或共享范围。文本最大 2 MiB。

DOC/DOCX、XLS/XLSX、PPT/PPTX 提供文字和基本表格阅读预览，原文件下载不变。单文件 10 MiB、OOXML 展开最多 32 MiB/4000 项；表格最多 20000 单元格，演示最多 200 页。复杂排版、宏、动画和公式重算不由阅读预览执行。PDF 使用随项目发布的本地 worker，HTTP IP 和域名均可预览。

## OnlyOffice

管理员在“账号与安全 → 服务配置”填写自行部署的 Document Server URL、至少 32 字符 JWT 密钥，以及 CloudNest 的完整访问地址。Document Server 和浏览器都必须能访问 CloudNest 地址；CloudNest 必须能访问文档服务。HTTPS 页面应配 HTTPS 文档服务，二者 JWT 密钥须相同。

保存并测试连接后，自己的 Office 文件预览中出现“Office 查看/编辑”入口。编辑保存验证文档服务签名、回调来源和文件修订号，保留旧版本；外部改动后需要重新打开。共享访客不获得编辑入口。编辑授权最长 12 小时；禁用账号、删除文件或外部修改修订号会使其失效。

## ZIP 下载

私人空间与分享页均可跨目录挑选文件和文件夹，所选篮子显示路径。私人空间创建前显示展开数量与空间估计，后台显示字节进度并可取消；分享页也显示进度和取消按钮。排队与构建任务会参与可用空间预估。

管理员可在服务器 `.env` 设置 `ZIP_MAX_BYTES`、`ZIP_MAX_FILES`、`ZIP_MAX_ENTRIES`、`ZIP_RETENTION_HOURS`、`ZIP_RESERVE_BYTES`，再重建 server 容器。默认分别为 536870912、1000、2000、1、268435456；入口仍最多 100 项。空间估计不能替代真实磁盘容量保障；文件变动、权限撤销、空间不足或任务取消后不能下载过期快照。

## 集合分享与文件收集

勾选项目后“分享选中项目”可创建集合链接，仅公开选中项目及其目录后代，支持提取码、到期时间、下载权限和打包。分享设置显示访问次数、下载请求数及收集数量；这些是请求计数，不是独立访客统计，事件保留 90 天。

文件夹更多菜单中的“收集文件”生成只上传链接。访客看不到已有目录和其他人上传的文件；上传使用随机重名后缀，受分享有效期、提取码、拥有者配额、限流约束。每个收集链接最多 100 个文件，每个文件最多 100 MiB。

## WebDAV、双重验证和邮件找回

“账号与安全 → 访问与恢复”可创建具名应用密码，选择只读或读写、1～365 天有效期。客户端地址为 `http(s)://服务器地址/dav/`，账号为登录用户名，密码为仅创建时显示的应用密码。最多 20 个，可单独撤销；登录密码和浏览器 Cookie 不能用于 WebDAV。支持 Class 1 的 PROPFIND、GET/HEAD、PUT、MKCOL、MOVE、COPY、DELETE，不提供 LOCK 和无限深度遍历。客户端应使用支持 Class 1 的方式；公网建议 HTTPS。

身份验证器支持标准六位 TOTP。启用时手动录入密钥并验证，立即保存十个一次性恢复码。使用过的时间步或恢复码不能重复使用；启用后登录需填写验证代码。丢失验证器和所有恢复码时，服务器维护人员可执行 `bash scripts/reset-mfa.sh 用户名`，输入该账号当前密码清除 MFA 并撤销全部会话及应用密码。忘记密码先按部署手册离线重置。邮件重置不会绕过双重验证。

管理员配置 SMTP 主机、端口、发件人、认证凭据及站点完整地址，并发送测试邮件。用户验证绑定邮箱后可在登录页找回密码；链接 15 分钟、一次有效，重置撤销所有登录会话及 WebDAV 应用密码。发送失败不向未登录请求透露账号是否存在，维护人员检查服务日志。更改站点地址时同步修改邮件配置。

## 存储策略与检索

管理员可添加最多 16 个私有 S3 兼容桶策略，测试写入、读取校验和清理，再选为默认上传策略。存量文件维持原策略；已有对象的策略不能直接换桶。凭据与服务配置加密保存于数据库，须连同 app_data 的签名密钥备份，接口不回传明文密钥。

迁移先切换默认策略再启动，任务逐对象复制、SHA256 校验后修改引用；来源副本保留。中断后可重试，已经完成的对象自动跳过；取消不撤销已完成对象。确认全部引用切换及备份后，由维护人员处理来源桶残留，不要直接删除仍被引用的对象。容量告警针对服务器磁盘，S3 桶的供应商配额需另行监控。

文件更多菜单可编辑标签；“标签与正文搜索”跨全部目录搜索名称、标签和文档正文。索引在后台生成，权限始终按当前用户过滤，回收站不参与搜索。文本、Office 与带文本层的 PDF 支持正文索引；不做扫描 OCR。PDF 最多 100 页，索引文本最多约 256K 字符；普通 LIKE 搜索适用于个人规模，超大库尚非分布式搜索引擎。

离线下载、团队协作和收费系统不在本轮实现范围。
