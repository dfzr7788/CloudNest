# 有界 Agent Runtime 与人工审批

当前为开发阶段，不是 2.1 稳定发布。发布门槛见 [实施状态](connected-workspace.md)。

## 启用与使用

默认关闭。隔离测试实例设置 `AI_ENABLED=true`、`AGENT_TOOLS_ENABLED=true`、
`AGENT_RUNTIME_ENABLED=true`；Docker Compose 已转发这三个配置。
管理员先在 AI 设置中配置自己的聊天模型并同意目标服务的数据发送，再打开
**节点中心 → Agent 运行**。运行页面另要求同意发送诊断目标和节点元数据，可能产生模型费用。

执行器复用既有 `ai_task(kind=AGENT)` 和 `ai_call`，不新增默认生产迁移。
相同 Idempotency-Key 和输入返回同一运行，不从上一次成功诊断缓存新请求。
节点中心可查询最近 30 条自己的运行；保留七天，失去管理员权限后无法读取。

## 循环与边界

- 从创建时起两分钟截止，排队时间也计算在内；最多六轮模型、八次工具。
- 每轮输出上限取模型配置与 1024 的较小值。累计保守预留预算 32768；已知实际用量更高时上调。
  这是 Token 调用预算，不是按供应商价格计算的货币支出上限。未知用量仍保留，不伪造零费用。
- 首次强制请求 `get_node_status`。返回真实合法工具调用才进入循环；忽略工具并返回文本时
  标记 `DEGRADED_QA`，不制造工具证据。上游拒绝工具参数时失败，不另发付费问答重试。
- 模型工具调用必须使用合法 ID、名称和严格参数；拒绝重复 ID、重复 JSON 键、尾随 JSON、未知工具。
  手动注册表仍只有五个只读工具；管理员权限在每个执行边界重新检查。
- 工具值、用户目标和模型文字都不构成后台指令。输出保持结构化数据，界面仅以文本呈现。
  固定工具白名单和独立授权限制行为；不声称能保证模型在语言层面永不受注入影响。
- 成功工具保存经过校验的参数、调用标识和真实观察结果；拒绝执行记录参数摘要与错误码。
  模型轮次先记录开始，调用费用另存 `ai_call`。中间证据在下一轮模型调用前提交；总记录限制 48 KB。
- 取消会标记任务并取消当前 HTTP 请求；超时、取消、网络错误和服务重启不自动重发付费请求。
  重启后运行中任务失败、未完成调用记为未知；保留此前步骤，用户显式决定是否新建运行。

五个诊断工具仍返回数据库快照，可能过期；管理员容量预算不是远端磁盘实测余量。
模型输出标记为推断，观察事实来自步骤中的工具数据。见 [只读工具契约](agent-tools.md)。

## 开发配置中的审批动作

人工审批依赖 `agent_approval`，仅在独立 `connected-dev` 配置中加载 V20 开发迁移并启用。
该配置同时包含同步开发模型，必须使用独立数据库和数据目录，不能指向唯一生产数据。
默认生产 Flyway 位置未改变；单独打开审批开关而缺表时启动失败，不自动创建表。

开发配置下，模型另可使用 `simulate_file_migration` 和 `propose_storage_action`，
参数仅含 `kind=MIGRATE|REPLICATE`、目标节点、1–20 个明确的文件 ID。
所有文件必须是调用管理员自己的可访问文件；不因管理员身份取得其他用户的文件操作权限。
模型不能调用人工批准或拒绝接口，没有 SQL、Shell 或对象存储写接口。

确定性模拟检查文件修订、SHA-256、主来源记录、目标准入、故障域、队列、去重对象、
使用量和预留预算。模拟不读取远端对象，也不预留空间；结果只在当前元数据条件下成立。
提案十分钟有效，记录内容摘要、有限输入和影响范围；每用户最多十条未过期待审批提案，保留七天。

**节点中心 → 操作审批** 可模拟、保存、人工批准或拒绝。人工批准必须携带当前提案摘要，
再次验证管理员和文件权限，并在用户锁、存储锁的同一事务中重新计算方案。
修订、节点配置或容量发生变化时拒绝旧提案，要求重新模拟。
有效批准只调用既有 `MigrationService.enqueue`；重复批准返回相同任务 ID。
`SUBMITTED` 表示排队，不表示对象复制或校验成功。请在迁移任务中检查实际完成和失败状态；
既有工作器负责真实复制与 SHA-256 校验，不删除来源。

接口、请求类型和错误条件见 [API](api.md) 与 [OpenAPI](openapi.json)。

## 本地验证与限制

执行器测试覆盖越权、撤销、未知写工具、格式错误、重复参数、调用次数、预算、取消和注入数据边界。
真实本机 HTTP 网关测试覆盖工具描述、强制探测、工具消息 ID 和显式调用次数；没有调用付费服务。
审批测试覆盖幂等、过期、拒绝、篡改摘要、文件/预算变更和跨用户拒绝。
模型供应商兼容性、真实双节点执行读回、重启故障注入和 VPS 负载仍需隔离验收。
普通用户文件 Agent、多实例工作器租约/fencing、货币价格预算仍未提供。
