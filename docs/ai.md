# AI 阅读助手与知识库

基础文件操作见 [使用说明](usage.md)，站点开关、密钥与恢复见 [部署手册](deployment.md#ai-部署与恢复)。本手册描述当前功能；[历史设计计划](ai-feature-plan.md) 保留原始方案与阶段记录。

站点默认关闭 AI。管理员开启后，进入“账号与安全 → AI 设置”：

1. 添加自己的 API 连接，填写显示名、包含版本路径的 HTTPS 公网根地址和 Key。例如 `https://provider.example/v1`，不要填写完整 `/chat/completions` 地址。
2. 添加聊天模型，手动填写供应商的模型 ID、上下文窗口、最大输出与 `max_tokens` / `max_completion_tokens` 兼容模式。保存配置不会产生请求。
3. 查看并确认该目的地的数据发送和费用说明。服务器调用时能解密 Key，运维者有技术访问能力；浏览器不持久保存 Key。目的地改变必须重新输入 Key 并重新同意。
4. 可显式测试模型，只发送固定短提示，可能收费。成功只代表本次聊天调用成功。
5. 打开自己的 TXT、Markdown、带文本层 PDF 或 DOCX，在预览中选择“AI 阅读助手”。桌面显示文档右侧助手，窄屏切换到助手，点击“返回文档”保留原阅读位置。先检查范围（不调用收费模型），查看修订、页数、字符数与预计调用次数，再确认生成摘要或建议标签。

连接测试最多输出 256 token，并受模型自身输出上限约束。供应商因输出上限中断时返回 `AI_OUTPUT_LIMIT`，不发布截断结果，也不自动重发；已返回的实际用量仍记录。

文本须为 UTF-8，最大 2 MiB；PDF/DOCX 最大 10 MiB。提取最多 100 页/262144 字符；扫描件无 OCR。DOCX 按正文段落与表格行提取，页眉页脚、图片文字、批注、文本框不在范围内；不伪造 Word 分页。可缩小从开头起的分析字符数；部分内容必须明确勾选同意，结果持续标示范围。长文分段摘要后合并，单任务最多 8 次调用，每次输入最多 24000 字符。未知模型按 UTF-8 字节数保守估计上下文，实际仍受供应商限制。

标签最多建议 8 个，选择后展示与当前标签的合并结果，确认才保存；总计最多 20 个、每个 40 字符。并发修改会拒绝保存并提示重新确认。

离开面板不会取消任务，返回后可从任务列表恢复查看。停止会中断正在运行的请求，但无法收回已发送数据，也不保证停止计费。超时、网络错误和服务重启均不自动重发收费请求。每日最多 100 次调用（包含测试和每个分段），UTC 00:00/北京时间 08:00 重置。“使用记录”中未返回的实际 token 显示未知，不代表零费用。

相同文件修订、模型配置、目的地、范围和语言可复用最近 7 天的结果；“重新生成”会再次调用。任务和缓存保留 7 天，用量保留 90 天，幂等记录保留 24 小时。可删除 AI 结果，源文件不受影响。文件或父目录回收后立即隐藏 AI 内容；恢复相同修订可恢复访问。摘要和标签在修订变化后不可读，问答旧会话保留为只读。永久删除源文件时，在同一事务中清除问答消息、引用和派生正文，用量统计保留。

当前支持语义搜索、知识库与人工确认的整理建议；不支持 OCR、图像理解或模型自主执行操作；公开分享、收集链接、WebDAV 无 AI 入口。只接受公网 HTTPS 443，暂不支持自定义额外端口和本地模型别名；服务器 localhost 是服务器自身。


## 单文档问答

打开文件预览 → AI 阅读助手 → **单文档问答与会话历史**，选择模型并点击“新建文档会话（不调用模型）”。输入问题后点击“发送问题”，核对目的地和费用提示并确认。只创建、打开或刷新会话不会调用模型。

每个问题最多 2000 字符，每次最多 1 次模型调用。短文档发送完整提取范围；长文档先在本地进行关键词检索，选择完整段落/行片段。超大单段放不进预算时会省略，页面提示仅覆盖部分内容；不做 OCR。最多携带 6 轮成功历史，预算不足时减少，历史不能替代原文证据。检索未命中时不调用模型，提示“在本次检索的内容中未找到依据”，不代表全文没有答案。若文档提取本身不完整，需要勾选同意仅使用已提取部分。

回答下方的来源按钮打开**当时实际发送的原文片段**，显示行、段落或页码。暂不精确跳转；关闭引用窗口即可回到当前文件预览。引用 ID 会核验，不能变成任意文件或外部链接；不代表模型每一句都已经人工核实。问答按纯文本展示，不执行模型输出的 HTML 或外链。

每个会话固定文件修订、模型和连接配置，修改文件、模型或目的地后旧会话只读，请新建会话。历史会话可在阅读助手重新打开后继续；每个会话同时只能生成一个回答。停止任务后可能已计费；失败、取消或重启中断不会自动重发，可点击“重新填写此问题”，检查后再次确认发送。

会话从最近活动起保留 30 天，每用户最多 200 个会话、每会话最多 100 个问题；问答正文、引用及其他 AI 派生内容共同受 100 MiB 上限约束。删除会话会停止任务并清除问题、答案和引用，保留源文件及不含正文的用量统计。平台清除当前副本不会同步清除供应商记录或历史备份。


## 向量模型配置与独立测试

“账号与安全 → AI 设置”将聊天模型和向量模型分开管理。只配聊天模型仍可使用摘要、标签和单文档问答。聊天 API 测试成功不代表供应商提供 Embeddings，也不能将聊天模型 ID 当作向量模型 ID。

1. 配置支持 Embeddings 的 API 根地址及 Key，并确认目的地和费用说明。
2. 在**向量模型**下点“添加向量模型”，按供应商规格填写模型 ID、预期维度（1–4096）、每批最多输入条数（1–32）和每批输入预算（512–32768 token，以 UTF-8 字节数加开销保守估计）。保存不发送请求。
3. 默认仅校验返回维度，不发送 `dimensions`。只有供应商和具体模型明确支持请求降维时，才勾选“按此维度请求降维”。不会自动改变维度、截断、补零或换模型。
4. 点击“测试向量模型”，确认后发送 1–2 条固定英文短句，最多一次 Embeddings 请求，不包含用户文件。检查向量数量、索引、维度、有限数值及非零范数；通过后只保存测试元数据，不保存测试向量。

向量测试与聊天测试独立，修改模型或连接会清除当前配置的测试状态。配置用途创建后不可修改，请新建另一用途的模型；向量模型不会出现在默认聊天模型或阅读助手选择器中。向量测试共用每日 100 次调用、排队、取消、幂等和用量记录；输出 token 对向量显示“不适用”，缺失的实际输入/总用量仍显示未知。失败、取消或超时不自动重发，可能已计费。

向量接口测试通过后可手动建立知识库索引；保存配置或上传文件均不会自动发送文档。接口测试通过不等于语义质量评估通过。

## AI 知识库与语义搜索

1. 在“账号与安全 → AI 知识库”新建知识库，选择自己的向量模型及文件/文件夹。文件夹只收录保存时的文件快照；每用户最多 10 库，每库最多 100 文件、1000 块。只配聊天模型的用户仍可使用原有阅读助手。
2. 点击“预览索引范围”，核对文件修订、提取完整性、块数与发送目的地。若有部分提取文件，需勾选同意。预览不会调用模型。
3. 点击“确认 / 继续索引”，确认正文发送及可能费用。每任务最多 8 批，未结束时可再次确认继续；已完成块不重发。失败或中断的未知批次可能已经计费，继续索引是一次新的人工请求。更换模型/维度/配置后不会复用旧向量；完整新代次准备好后才切换。
4. 输入问题并确认“检索相关片段”，仅发送问题给向量供应商，最多一次调用，返回至多 6 个当前可访问片段。没有统一相似度阈值，相关片段不代表一定存在答案；仍可使用云盘原有文件名、标签和正文搜索。
5. 需要生成回答时选择聊天模型，点击“基于这些片段回答”并再次确认。问题、片段及有限历史发送给该聊天供应商；向量和聊天供应商可能不同。模型只能引用本次来源，未知引用会被移除；无有效引用则显示无依据提示。点击来源再次鉴权后查看原文。
6. 问答支持历史会话、删除和任务取消。切换索引代次或修改聊天模型/连接配置后旧会话只读，继续提问会新建会话。会话最近活动后保留 30 天，普通搜索任务保留 7 天；问答引用使用的搜索任务随会话续期。清除知识库会删除索引及本库问答，不删除源文件。

修改文件后需手动更新，未改文件可复用。新增文件需“修改范围 / 刷新文件快照”后再建索引。文件移出所选目录、回收或修订变化立即排除；永久删除同步清除向量和关联任务正文。界面提示需要更新时，搜索仍可使用未变化的有效片段；旧修订不会作为当前资料返回。未完成代次 7 天后清理，完整索引保留至手动删除或源文件失效；派生数据（含向量预留）共用每用户 100 MiB 限额。

## AI 版本变化摘要与智能整理

- 文件预览 → AI 阅读助手 → 版本变化摘要：选择两个仍存在的版本（可选当前版本），先查看不收费的确定性增删差异，再确认发送差异让聊天模型解释。每边最多 1000 提取行、60000 字符，差异最多 20000 字符；模型上下文更小时进一步拒绝；任一版本无可提取正文也会拒绝。PDF/DOCX 行号是提取文本行号，不是排版页内行号；无变化时不调用模型。版本删除或当前修订变化后，旧任务不可再作为有效比较读取。
- 账号与安全 → 智能整理：选至多 8 个文件、至多 20 个允许的目标目录和聊天模型，预览每文件前 1000 字符的范围，确认后生成文件名、标签、目录及理由建议。默认全部不勾选，模型不能修改文件。
- 逐个勾选改名、标签合并或移动后点击“确认应用勾选项”。服务器重新核对源修订、文件名、位置、标签和目标权限，冲突文件单独报告，其他文件可成功。同名文件不覆盖，标签只合并；再次提交已应用项不会重复执行。同一文件的一次应用后若还想采用其他建议，请重新预览生成，以当前状态为准。
