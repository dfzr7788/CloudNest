## 本轮实现说明

- [Agent Runtime 与审批](agent-runtime.md)：运行复用 `ai_task(kind=AGENT)` / `ai_call`。
  六轮模型、八次工具、从创建起两分钟、累计保守预算 32768、48 KB 结果；无隐式付费重试。
  成功工具参数与事实、拒绝摘要、模型推断和计费记录分别可查；失败/重启保留证据并标记停止。
- [同步协议与开发服务](sync.md)：默认生产不创建新表；开发配置加载 H2/MySQL V19/V20。
  变化 feed 明确为协调后的最终状态，不是完整操作审计；旧游标要求重取快照但保留本地基线。
- [Windows 客户端](../clients/windows-sync/README.md)：命令行、桌面目录选择、选择性传输、状态/冲突记录、
  用户级 Start 菜单安装入口。凭证不落 SQLite。下载不覆盖提交瞬间新出现的本地文件；原版本保留在回收目录。
- 节点中心新增“操作审批”和“资源拓扑”；批准只表示提交任务，不制造复制/校验完成状态。
  模型没有批准接口、任意命令或对象存储写工具。

### Windows 源码安装包维护

安装包固定清单增为 8 个文件，包含 `uninstall.ps1`。安装前验证包内 SHA-256 清单；标记安装所有权及各文件摘要，拒绝覆盖改动过的文件、未标记的非空目录、符号链接/junction 路径或其他安装的快捷方式。源码目录没有发布清单时仍可供开发使用，不将本地清单校验声称为代码签名。

卸载只删除本安装摘要匹配的固定文件和其快捷方式，不递归删除目录；修改文件、未知内容、同步目录/日志/冲突副本和 Windows 凭据保持原样。需要撤销设备时，先在客户端 logout 或网页撤销。保留修改文件时，卸载脚本和所有权标记也保留，方便人工检查。

原生 Windows 临时目录测试覆盖中文/空格路径、安装升级卸载、修改/未知文件保留、包与标记篡改及 junction 拒绝。CI 增加独立 Windows 门禁，成功后才允许 Linux 构建与发布；Linux 仍校验安装包清单，跳过原生 PowerShell 场景。没有操作本机真实安装目录、开始菜单目录或凭据，也未替代真实双 PC/桌面人工验收。
