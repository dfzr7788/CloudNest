# CloudNest 界面设计规范

## 当前视觉方向

根据用户提供的 Raycast / Linear 深色参考，采用紧凑的炭灰工作空间。界面依靠灰阶、字重、细分隔线和悬停反馈建立层级；低饱和蓝紫色只用于上传、进度、焦点和少量操作强调。

文件内容直接铺在主工作面中，统计为轻量信息栏，集合与筛选共用工具栏。取消大块浅色统计卡和文件区外框，默认列表保持高信息密度。

## 设计变量

统一变量位于 `cloudnest-web/src/styles/tokens.css`。

| 用途 | 规范 |
| --- | --- |
| 工作面 / 导航 | #202124 / #1D1E21 |
| 浮层 / 控件 | #252629 / #292A2E |
| 选中 / 悬停 | #32343A / #2E3035 |
| 标题 / 正文 / 次要文字 | #EEEEF0 / #D3D4D9 / #999BA5 |
| 主按钮 / 链接 | #6266C8 / #AFB2FF |
| 正文字号 / 页面标题 | 14px / 20px |
| 间距 | 8 / 16 / 24 / 32px，紧凑工具区允许 4 / 6 / 12px |
| 圆角 | 控件 6px，文件与面板 8px，主要弹窗 12px |
| 动效 | 160ms，系统减少动态效果时停用 |

次要文字在工作面上的对比度约 5.82:1；主按钮白字对比度约 4.94:1。链接使用更亮的强调色，避免直接复用按钮背景色作为文字色。

Element Plus 使用现有依赖自带的 dark CSS variables，所有弹窗、下拉、表格、表单、消息等统一使用深色变量。页面 HTML 提前声明深色，避免启动时闪白。没有新增运行时依赖。

## 布局与组件

- 桌面导航 220px，顶部工具栏约 56–60px；中屏使用图标导航，手机使用抽屉。
- 页面标题与操作保持一行；统计信息收为文本和小图标。根目录路径和高级搜索单独成行，集合、筛选、排序、视图切换集中排列。
- 文件列表桌面行高 48px，手机 56px；名称、大小、修改时间表头可排序。次要操作在悬停、键盘聚焦或选中时显示。
- 网格按宽度自动排布，弱化卡片外框；选中时用中性灰背景与清晰描边区分。触摸设备始终显示操作入口。
- 文件夹、文档、图片等使用低饱和辅助色；空状态插画保持炭灰与灰紫色。
- 上传任务为紧凑深色浮层，暂停、续传、失败重试与取消沿用现有流程。没有下载任务时使用轻量文本区。
- 文档阅读和 AI 侧栏使用同一深色主题，代码高亮使用现有 Highlight.js 深色样式。PDF 原文画布保留文件本来的白底，图片保持中性深色画布。
- 登录与注册使用安静的深色双栏布局，左侧为品牌与文件工作区示意图，右侧为统一高度的表单。手机保留品牌标识。
- 分享、回收站、账号安全、管理员设置、版本、知识库与整理面板使用同一套颜色和容器规范。

## 交互与约束

保留原有路由、API、权限控制与业务处理。列表排序、收藏/最近集合、跨目录选择篮、复制剪切、分片上传、预览、AI 调用确认、分享权限和危险操作确认继续使用原实现。

Ctrl / Command / Shift 点击网格切换选择，普通点击打开；批量栏仅在选择后出现。焦点轮廓保持可见，手机主要触摸目标保持 44px。减少动态效果偏好同时应用于 CSS 动画和滚动。

## 验证

生产构建包含 TypeScript 检查。Playwright 覆盖六种视口、加载/空/失败状态、菜单和焦点、真实上传与下载、分享和回收站、安全设置及受控 AI 流程。视觉截图单独检查登录、列表、网格、阅读器、弹窗和移动端。
