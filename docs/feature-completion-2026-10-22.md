# 功能完整性检查与补齐（2026-10-22）

本次对照 Horizon Next 文档、团队 API 和浏览器界面检查功能闭环，补齐团队管理流程；未将所有预览功能标记为生产完成。

## 本次已补齐

| 缺口 | 完善结果 |
| --- | --- |
| 邀请只能创建，无列表和撤销入口 | 增加最近 100 条邀请、到期时间、状态、确认撤销；复用已有授权接口 |
| 邀请有效期固定 24 小时 | 支持 1～168 小时，与服务端约束一致 |
| 权限只能写入，无法查看原设置 | 从文件行或 ID 读取现有 ACL，选择成员时回显，支持恢复继承 |
| 成员修改失败仍显示新值 | 由服务端成功后的刷新更新显示，失败时保留原值 |
| 管理员可点击所有者专属操作 | 隐藏授予/管理 Admin 的入口，保留服务端权限检查；移除成员加确认 |
| 刷新团队资料影响权限编辑 | 仅团队 ID 或目标条目变化时清空表单，忽略过期读取结果 |

邀请令牌不保存在浏览器存储中，列表不返回令牌或其哈希。已有邀请无法找回令牌，需要撤销并重建。

## 仍需独立完善或验收

- Windows 盘符目前为 WebDAV MVP；原生 WinFsp、可靠离线缓存和安全写回队列未实现。
- 客户端加密保险箱未实现，不能声称零知识加密。
- 团队文件未接入个人 WebDAV/同步客户端；不能用个人接口访问团队资源。
- 公网直传仍是默认关闭的原型，需要目标存储的 CORS、POST-policy 与过期回退实测。
- 跨物理机器故障、真实 Windows 断网/大文件、低内存与长期运行仍需专门环境验收。
- 新增浏览器流程使用受控 API 夹具；后端集成测试单独验证真实邀请撤销、ACL 读回及授权变化，不替代上述部署验收。
