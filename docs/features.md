# 功能说明

[文档中心](README.md) · [使用说明](usage.md) · [部署与维护](deployment.md)

本文描述 CloudNest `1.0.0` 的现有能力。具体操作见[使用说明](usage.md)，服务配置见[进阶配置](advanced-features.md)，安装维护见[部署手册](deployment.md)。数量限制为默认值，允许配置的项目以实际部署为准。

## 个人文件与传输

支持目录管理、列表与网格、收藏、最近使用、标签、名称筛选和正文搜索。可跨目录选择最多 100 个入口，执行复制、剪切、移动、删除、分享和打包。复制保留当前内容、目录结构与标签，不复制历史版本或分享链接，每份副本独立计入逻辑配额。

上传支持文件夹、SHA-256 校验、并发分片、暂停与续传，以及覆盖并保留历史、保留两份、跳过三种同名策略。默认单文件最大 2 GiB；文件夹上传最多 2000 个文件、32 层。浏览器会尝试保留上传队列与文件内容，刷新后恢复任务；原文件缓存被清理时需重新选择并核验原文件。未完成会话默认保留 24 小时。

单文件直接下载，目录或多选项目通过后台 ZIP 任务下载。默认最多 1000 个文件、2000 个文件与目录、512 MiB，任务保留 1 小时，可查询进度并取消。权限或源内容变化可能使任务失效。

## 预览、搜索与分享

| 功能 | 范围 |
| --- | --- |
| 阅读预览 | 图片、PDF、文本、Markdown、Office 文本和基本表格，以及浏览器支持的音视频 |
| Markdown | 数学公式、代码高亮、表格和权限内的相对附件；不自动加载远程图片 |
| Office 编辑 | 需管理员接入 OnlyOffice；公开分享访客不能编辑 |
| 正文搜索 | 文本、Office、带文本层 PDF 的后台索引；不包含扫描 OCR |
| 历史版本 | 下载、恢复和清理，最多保留 20 个历史版本 |
| 公开分享 | 文件、目录和集合，支持提取码、有效期、下载权限、撤销与请求统计 |
| 文件收集 | 只上传链接，访客看不到已有文件；每个链接最多 100 个文件，每个 100 MiB |

文本与 Markdown 阅读默认最大 2 MiB，Office 阅读最大 10 MiB。Office 阅读不保证复杂排版、宏、动画和公式重算；音视频不提供服务端转码。单文件分享固定创建时的内容版本，目录分享展示当前有效后代。

## 团队空间

侧栏「团队空间」提供团队创建、成员邀请、文件浏览、分片上传、同名版本更新、移动、回收站、空间管理及审计。团队文件归属于独立资源账户，通过团队权限访问。

| 角色 | 权限 |
| --- | --- |
| Owner | 管理文件、成员、团队配额和资源 |
| Admin | 管理团队文件、目录授权、邀请、快照和节点审核；不能授予或修改其他 Admin |
| Editor | 在授权范围内上传、更新、移动、新建和删除 |
| Viewer | 在授权范围内浏览和读取 |
| Contributor | 独立的存储贡献授权，可与文件角色组合；单独贡献不授予文件读取权 |

「成员与权限」支持创建 1～168 小时的一次性邀请，查看最近 100 条邀请及撤销有效邀请。令牌仅在创建时展示，遗失后需撤销并重建。

目录 ACL 支持 READ、WRITE、DENY 和 INHERIT，用于收紧成员角色权限；子目录不能扩大父目录或角色权限。选择继承会移除该成员的单独设置。上传每个分片及完成提交都会重新鉴权，成员中途被降权后不能继续提交。

创建团队须从 Owner 的个人可用配额中划拨空间；调整时同时检查个人和团队的已用与预留空间。团队管理员可创建团队快照、恢复任务，并提交文件迁移或异域副本任务。个人 WebDAV 和同步客户端目前不暴露团队文件。

## 快照、恢复与巡检

侧栏「数据保护」提供目录快照、历史树、新增/修改/删除/移动比较、恢复预览、单文件或子树恢复，以及定时策略和任务控制。「显示所有历史目录」可查找源目录已删除或已清空回收站的快照。

恢复目标由当前所选目录决定，恢复始终创建副本，保留当前文件。任务支持暂停、取消和失败重试；取消不删除已经生成的副本。对象不可用、配额不足或目标目录删除会明确报告失败。

快照引用已有内容对象，物理对象可复用，但每个快照的文件总大小仍计入逻辑配额，恢复副本另计。单次快照最多 20000 项，每个归属账户最多 500 个快照；仍被可重试恢复任务引用的快照不能清理。当前文件、版本、分享或快照仍在引用的对象不能回收。

系统管理员可配置定时完整性巡检和读取限速，按节点、账户或目录筛选。巡检记录损坏或不可用对象；仅在确认有效副本后请求修复，没有有效副本时报告 `NO_VALID_REPLICA`。普通、重要、归档保护预设的实际效果取决于任务结果、节点健康和副本校验；独立备份需另行配置。

## 存储节点与贡献

「节点中心」统一管理本地和 S3 兼容存储连接、容量预算、健康状态、故障域、调度及迁移。支持手动、容量、稳定性和高可用调度；上传会话固定目标并预留容量。高可用模式异步创建异域副本，上传完成后仍需检查实际保护状态。

迁移先复制并校验长度与 SHA-256，再切换引用，来源对象保留。受保护对象经校验后读取，可在有效副本间故障切换并安排修复。节点预算、物理占用和用户逻辑配额分别统计，副本不会增加用户可用配额。详细约束见[存储节点与副本](storage.md)。

团队贡献节点流程为：管理员授予 Contributor → 成员登记目录节点 → 团队管理员审核 → 系统管理员检查地址和故障域并完成认证读写探测 → 节点心跳与调度。贡献仅供所属团队使用；超过 120 秒未收到心跳、撤权或健康失效时停止新任务。停用不自动删除数据。安装见[轻量节点说明](../clients/storage-node/README.md)。

下载直连前探测 CORS / Range，失败回退代理。公网 S3 上传原型默认关闭，需节点公开 HTTPS 地址和存储端 CORS / POST-policy，最多 100 MiB、授权 60 秒，失败回退分片代理。服务端仍需验证内容并再次写入。冷热规则仅提供候选建议，不自动搬迁。

## 账号、AI 与客户端

支持邀请注册、会话撤销、密码修改、TOTP 与恢复码、邮箱验证和找回。WebDAV 使用独立应用密码，可设只读或读写并单独撤销。SMTP、OnlyOffice 与外部存储均为可选配置。

AI 默认关闭，用户配置自己的兼容 API 与模型。可手动请求摘要、标签建议、文档问答、知识库检索、版本解释与整理。上传和保存配置不会自动调用模型；调用前确认数据发送与费用。详见[AI 使用说明](ai.md)。

管理员可启用只读诊断及有界 Agent；Agent 受工具白名单、轮次、调用次数和截止时间约束。人工批准提案后由确定性服务提交任务，批准不代表任务执行完成。站点功能开关位于「账号与安全 → 集成服务」，保存后立即生效并持久化；Agent 另需站点 AI、只读诊断和模型配置。

Windows 同步提供 CLI 与 Tk 桌面原型、选择性传输、冲突副本和本地任务队列。盘符映射使用 WebDAV，账号安全中创建应用密码后运行：

```powershell
.\clients\windows-sync\mount.ps1 -Server https://cloud.example.com/ -Drive N
```

脚本交互读取凭据，使用 `-Unmount` 卸载。客户端安装与恢复见[Windows 客户端](../clients/windows-sync/README.md)。

## 功能边界

- 当前稳定版后端仅支持单实例；多存储节点不等于多业务实例高可用。
- Windows 同步仍为开发原型；盘符使用系统 WebDAV 缓存与大小限制，未实现原生 WinFsp、可靠离线缓存和安全写回队列。
- 客户端加密保险箱尚未实现，不提供零知识加密。
- 公网直传仍为默认关闭的原型，须针对目标存储验证兼容性。
- 真实跨物理机器故障、Windows 断网与大文件、低内存和长期稳定性仍需部署环境验证。
- 双副本和目录快照不能替代独立备份；数据库、内容对象、配置和密钥应成套恢复。
