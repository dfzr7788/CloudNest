# 文件夹压缩下载

## 从哪里下载

- 在“我的文件”勾选文件或文件夹，点击工具栏“打包下载”。按钮始终显示，未选择时置灰，支持多个文件夹和混合选择。
- 单个文件/文件夹可在“…”菜单选择“压缩下载”，列表和网格都有入口。
- 提交后页面滚动到“下载任务”；状态变为“可下载”后点击“下载 ZIP”。刷新页面仍可查看任务；重新打包使用原来选择的根项。

例如选择 algo 和 en 后，包内是 algo/、en/ 两棵目录树。子目录、中文文件名、空目录均保留；同时选中父文件夹和其中的文件只收录一次。回收站内容不收录。

## 内容与边界

任务按创建时的内容生成快照。后续新增文件不自动加入旧包；修改文件内容、重命名/移动快照项、删除任何快照项会让旧包不可下载，需重新打包。分享包还会复核全部后代是否仍在分享范围，移出子树的内容不能通过旧包访问。

最多选择 100 个根项，展开后最多 1000 个文件、2000 个文件与目录、64 层、总文件大小 512 MiB；超限会明确报错，不截断目录。每用户同时最多 2 个任务，每小时最多保留 10 个任务，产物有效期 1 小时。

同名根文件夹、忽略大小写后重名、文件与文件夹同名时自动添加编号。Windows 不适用的字符和设备名会替换或加前缀，避免解压冲突和危险路径；中文与普通名称保持。压缩包内路径最大 4096 个 UTF-8 字节。

## 更新部署

本次同时修改前后端并新增数据库字段，需要完整更新。已启用更新服务的管理员可到“账号与安全 → 系统更新”检查并更新；没有启用时，在备份后手动执行 `git pull --ff-only` 和 `docker compose up -d --build`。

更新后按 Ctrl+F5 刷新。此前只有文件打包功能，选中文件夹不显示按钮；本版补齐文件夹支持及显式菜单入口。
