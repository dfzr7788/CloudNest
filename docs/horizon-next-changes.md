# Horizon Next 变更记录

## 2.3.0-dev.1 — 2026-10-20

包含 2.2 Data Resilience 和 2.3 Distributed Workspace 的连续开发内容：

- 增加不可变目录元数据快照、历史结构与差异、单文件/目录恢复预览和保留冲突的恢复副本。
- 将快照引用纳入对象回收约束、配额及离线维护审计；按保留策略清理，保护进行中及可重试恢复引用。
- 增加共用持久化恢复/巡检队列、幂等、逐项进度、暂停/继续/取消/重试及重启检查点恢复。
- 增加限速流式 SHA-256 巡检，标记损坏/不可用状态，通过既有迁移服务请求可审计副本修复；无有效副本时停止自动修复并告警。
- 增加直连下载能力探测和代理回退；S3 POST-policy 上传原型，精确大小/对象绑定，服务端校验，分离暂存 key 与正式 key，默认关闭。
- 增加基于访问时间的冷热分层建议和三个受原有白名单限制的只读 Agent 运维工具。
- 增加独立团队资源归属、角色、目录 ACL、单次邀请、配额划拨、回收站、文件版本上传、审计和团队存储任务入口。
- 增加经过团队和系统管理员两级审核的成员节点登记、心跳、故障域/性能能力、团队限定调度及停止新分配。
- 提供只服务明确授权目录的 Python 轻量节点，容量限制、流式读写、Range、原子写入、认证和路径隔离。
- 提供 Windows WebDAV 盘符映射脚本，使用独立应用密码并纳入同步客户端源码安装包。
- 增加中英页面、后端 H2/MySQL 集成、真实轻量节点进程联调、S3 协议夹具与浏览器流程测试。
- 不修改 V1–V18；V19/V20 按原校验和进入规范迁移目录；新增 V21/V22，并扩大节点标识字段以兼容成员节点。

本版本仍为开发预览。原生虚拟磁盘的离线缓存/待写回管理、客户端加密保险箱、所有历史任务物理表统一尚未实现；Windows 实机、真实 Garage、公网故障、低内存与长时间稳定性验收尚未完成。详细使用与边界见 [Horizon Next](horizon-next.md)。
