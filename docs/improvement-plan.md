# CloudNest 现有功能改进与新增功能计划

> 编制日期：2026-10-16。状态：主要功能已实施；实际结果与剩余细节见 [改进验收报告](improvement-report.md)。
> 依据：现有源码、README、plan.md、验收清单与执行日志。优先级是针对当前私人云盘的产品判断，不是外部市场调研结论。
> 原计划继续记录已交付范围；本文作为后续增量开发的执行依据。实施时逐项记录预期、实际和证据。

## 1. 改进方向

下一版应让 CloudNest 从“能完成核心操作”发展为“适合每天使用”。优先解决账号维护、整批资料导入、快速找文件和批量整理，再扩展分享与文件保护。

现有能力已经包括：多用户隔离、目录管理、拖放及批量文件上传、分片续传、同用户秒传、搜索排序、列表/网格、图片/PDF/文本预览、单文件分享、回收站、配额、批量文件 ZIP 下载。已有能力不重复列为新增功能。

当前明确边界：个人资料仅修改昵称；刷新后续传需重选原文件；分享对象为单文件；打包有文件数与容量上限；本机恢复已经验证，真实 MinIO、Linux/HTTPS 和生产数据成对恢复仍待验收。74 次历史验证是既有版本的证据，不覆盖本文新增需求。

## 3. 第一批详细计划

### I01：账号与会话管理

- 场景：用户需要修改密码，或在借用设备登录后远程退出。
- 范围：账号设置页增加“修改密码”“当前登录会话”；展示当前设备标记、最近活动时间及粗粒度客户端信息；支持退出其他会话。
- 规则：修改密码必须校验旧密码，成功后撤销所有已有会话并要求重新登录；失败不修改密码。会话标签仅辅助识别，不宣称能准确识别物理设备。不向其他用户暴露会话信息。
- 找回密码：第一批提供受控的本机维护重置流程并记录操作；自助邮箱找回单独安排，必须先具备已验证邮箱和邮件发送条件，不能只凭账号名重置。
- 改动：扩展认证接口和会话元数据；增加设置页；记录密码变更和会话撤销事件，不记录密码或原始令牌。
- 预期验收：旧密码错误返回明确失败且原会话可用；正确修改后旧密码不能登录，旧 Cookie 访问被拒；新密码可登录；A 无法读取或撤销 B 的会话。

### I02：文件夹上传与冲突处理

- 场景：上传“课程资料/章节/讲义.pdf”时保留目录结构。
- 范围：新增“上传文件夹”，支持目录拖入的浏览器增加拖入入口；不支持的浏览器显示兼容说明并保留文件选择。继续复用分片、续传、校验和配额机制。
- 规则：服务端逐级创建虚拟目录，拒绝绝对路径、越级路径和非法名称；目录深度、条目数设置可配置上限。浏览器无法枚举空目录时明确提示，不能宣称完整保留空目录。
- 冲突：首版只提供“跳过”“保留两份”，可应用于本次剩余冲突；默认不覆盖。同名目标发生并发变化时重新校验。待 I08 完成后再增加“保存为新版本”。
- 失败处理：逐文件记录结果，允许仅重试失败文件；已成功文件不回滚、不重复计费；用户主动取消不自动删除已经上传成功的内容。
- 预期验收：三层目录上传后结构和摘要一致；同名文件按选择跳过或生成新名；中断后成功条目保持不变，重试仅处理未完成项；恶意相对路径不产生越界目录；容量不足明确列出失败项。

### I03：批量整理与选择体验

- 场景：一次选择多份资料移动、删除或恢复。
- 范围：列表/网格统一多选；当前页全选、已选数量、取消选择；批量移动、移入回收站、恢复、彻底删除；保留现有批量 ZIP。
- 规则：切换目录或筛选条件后清空选择并提示；首版“全选”仅指当前页。多选同时包含祖先与后代时合并处理，避免重复计费或重复删除。
- 执行方式：逐项返回成功/失败及原因，不承诺跨全部条目原子回滚；再次提交不得重复结算。同名、目标失效、目录成环等失败应可定位。
- 交互：普通删除提供短时“撤销”入口，复用恢复能力；彻底删除明确显示数量及不可恢复提示，并保留确认步骤。撤销时出现同名仍遵循恢复冲突规则。
- 预期验收：多选 10 项，其中 1 项冲突，显示 9 成功/1 失败；祖先和子项同时选中只处理一次；取消确认不改变数据；刷新后状态与提示结果一致；不能批量操作其他用户资源。

### I04：快速查找与个人整理

- 场景：用户希望快速打开常用资料、找到刚上传的文件、筛选大文件。
- 范围：收藏文件/文件夹；最近上传和最近打开；类型、大小区间、时间区间筛选；明确“当前目录/全部文件”的搜索范围；搜索结果可打开所在目录。
- 规则：收藏绑定条目 ID，移动和重命名不丢失；软删除后从收藏入口隐藏，恢复后重新可见；彻底删除清理收藏。最近打开仅记录拥有者成功预览，不把分享访客行为混入。
- 数据：增加用户收藏和最近访问记录，设置保留数量；名称筛选先使用现有数据库，暂不引入独立全文检索服务。
- 预期验收：收藏后换设备登录仍可见；重命名后收藏显示新名；筛选结果和总数一致；同名跨目录结果能准确定位；B 搜索不到 A 的条目。

### I05：传输中心与错误反馈

- 场景：同时传多个文件时需要知道谁在传、为何失败、如何恢复。
- 范围：统一展示等待、校验、上传、暂停、合并、完成、失败、取消；显示已传字节、估算速率和剩余时间；全部暂停/继续、失败项重试、清除已完成记录；整合 ZIP 生成与下载入口。
- 规则：校验和合并阶段不显示虚假上传速率；剩余时间无法估算时显示“计算中”；已完成表示服务端校验和元数据提交完成，不能只凭请求已发完。刷新后的上传仍保留重选原文件要求。
- 边界：首版记录下载任务生成及链接状态，不宣称掌握浏览器下载到本地磁盘的真实完成进度。会话过期时引导登录后恢复，不把认证失败无限重试。
- 预期验收：限速场景进度持续增长且不超过 100%；断网可见暂停或失败原因；重试不重复创建文件；刷新后可恢复未过期上传；ZIP 失败原因、过期状态和重新创建入口可用。

### I06：实际运行与交付完善

- 范围：落实目标环境上的部署、HTTPS、真实对象存储验收、数据库和文件的成对备份恢复；增加磁盘余量、临时文件占用、失败清理任务和备份最近成功时间等运行指标。
- 依赖：目标服务器及存储方案。沿用本地私有存储也能部署，不强制先迁移对象存储；选择 MinIO 时必须获得实际可运行的目标服务并完成验证。
- 规则：默认关闭不受控公开注册或使用邀请注册；备份策略明确频率、保留周期、加密/访问权限及恢复步骤。健康指标不得向普通用户暴露密钥或其他用户信息。
- 预期验收：服务器重启后数据仍在；HTTPS 下上传、预览、Range 和分享完整可用；从独立备份恢复到新环境，抽样及关键文件摘要一致；磁盘不足时拒绝新任务且已有文件不损坏；升级失败可按手册恢复。
- 状态记录：未提供环境时标记“待环境验证”，保留具体步骤，不勾选通过。既有 S3 模拟契约测试不能代替真实存储服务验收。

## 4. 第二批新增功能

### I07：文件夹分享与分享管理

- 新增文件夹分享、目录浏览及受限打包；分享管理支持按有效/过期/撤销筛选和修改有效期。
- 默认是“当前目录内容的动态分享”：新增后代会进入分享范围，创建时明确提示；移出目录的文件立即失去通过该分享访问的权限。
- 每次列举、预览、下载都验证条目仍位于分享根目录之下；目录移动、软删除、提取码更新和撤销后，旧授权按规则失效。访客不可上传、修改或删除。
- “仅预览”表示禁用下载入口和下载接口，不能保证阻止截屏或保存已呈现内容，界面不得作此承诺。
- 验收：访问范围不能逃出分享子树；分享撤销后旧访客凭证不能继续访问；ZIP 创建与下载均复核权限；当前 100 文件/512 MiB 等限制在扩展前继续生效，超限明确提示。

### I08：文件版本历史

- 新增“保存为新版本”、查看历史、下载历史和恢复旧版本；普通上传仍默认保留两份，避免无意覆盖。
- 设计独立版本记录与当前版本指针，blob 引用包含全部保留版本。容量按所有逻辑版本大小累计；恢复旧版本切换当前指针，不重复复制或重复计费。新增版本保留上限由配置决定，自动清理规则上线前明确展示。
- 单文件分享默认固定到创建时的版本，更新文件不会悄悄替换访客拿到的内容；文件夹动态分享显示当前版本，两个语义必须清楚标注。
- 验收：上传 V1/V2 后分别下载摘要正确；恢复 V1 后当前内容准确，V2 仍在历史中；两个并发更新可检测冲突；清理旧版本不会删除其他条目引用的 blob；配额不足时旧当前版本不改变。

### I09：预览体验与媒体支持

- 图片增加缩略图、上一张/下一张、缩放与旋转；PDF 增加缩放、页码跳转和加载反馈。
- 音视频首版仅对浏览器可解码格式提供受鉴权的 Range 播放；不支持的格式继续下载，暂不加入转码集群。
- 缩略图异步生成并缓存，设尺寸、解码资源及任务数量限制；原图失败不影响文件保存。派生文件继承原文件权限且在彻删后清理。
- 验收：大图列表无需逐项加载原图；图片方向正常；播放可拖动进度；非支持格式有清晰提示；源文件权限失效后原图、缩略图和媒体地址都无法继续新请求访问。

### I10：空间与回收站管理

- 新增有效文件/历史版本/回收站/上传预留的占用分解、大文件筛选、清理建议；回收站增加批量清空和可配置保留期限。
- 自动清理默认关闭；启用时显示具体期限，截止时间按服务器时间计算。提供清理记录，不将物理去重节省量与逻辑配额混淆。
- 验收：分项之和与用户计费口径一致；未过期条目保留；到期清理和重复执行不重复扣减；清空一个副本不破坏其他引用；清理后空间显示及时更新。

### I11：管理与活动记录

- 管理员可邀请/禁用用户、调整配额、查看系统占用和维护任务；普通用户可查看自己的上传、移动、删除、恢复、分享、密码变更记录。
- 明确角色边界，管理员管理系统不默认获得浏览私人内容的入口。初始管理员采用本机维护命令创建，禁止首个公网注册者自动成为管理员。
- 账号禁用撤销会话并阻断新请求；降低配额不能低于已用与预留总量。活动记录设置保留期和分页，不保存提取码、密码、令牌和文件正文。
- 验收：普通用户无法调用管理接口；禁用后旧 Cookie 失效；越权访问日志记录被拒；A 看不到 B 的操作记录；失败的文件操作不能记成成功。

## 5. 暂缓项目及启动条件

| 项目 | 何时值得做 | 先满足的条件 |
| --- | --- | --- |
| WebDAV | 需要挂载系统文件管理器或接入笔记工具 | 独立应用密码、撤销机制、协议兼容与权限测试 |
| 文档全文检索 | 文件名搜索已不足以定位大量资料 | 受限解析任务、索引隔离、删除同步、资源预算 |
| Office 在线预览 | 经常浏览 Word/Excel/PPT | 明确转换服务部署和许可条件；先做预览再考虑编辑 |
| AI 搜索/总结 | 有明确问答场景和成本预算 | 文本提取、权限过滤、外部内容发送选择、删除同步 |
| 原生客户端/自动同步 | 确实需要持续同步本机目录 | 版本冲突、删除传播、断网及恢复协议已设计 |
| 多实例/跨用户去重 | 单实例容量或吞吐成为实测瓶颈 | 重构并发协调及权限模型，并有压测证据 |

## 6. 实施顺序与工作量估算

估算是单人有效开发时间，包含设计、实现、回归和记录，不是交付承诺；不包含等待服务器、证书、邮件等外部条件的时间。

| 阶段 | 工作 | 估算 | 阶段退出条件 |
| --- | --- | --- | --- |
| R0 | 细化接口、迁移与用例；确定目标运行环境 | 2～3 人日 | 新增规则和验收编号固定，历史完成项不变 |
| R1 | I01 + I03 | 5～8 人日 | 密码/会话和批量整理闭环，越权及重复提交通过 |
| R2 | I02 + I05 | 7～11 人日 | 整个资料目录可上传，中断、冲突和失败可恢复 |
| R3 | I04 + I06 | 6～10 人日 | 常用文件可快速定位；目标部署恢复通过或明确环境阻塞 |
| R4 | I07 + I08 | 10～16 人日 | 分享边界、历史恢复、引用清理与配额一致 |
| R5 | I09 + I10 + I11 | 10～17 人日 | 媒体、空间和多人管理逐项验收 |

第一批 R0～R3 合计约 20～32 人日。建议先交付第一批，再根据真实使用反馈决定第二批范围。I08 必须先确定版本模型才能开放覆盖上传；I07 后续接入版本时必须补测分享固定版本语义。I06 的环境准备可以提前进行，不阻断本地功能开发。

## 7. 每项结果的记录要求

沿用现有记录体系，新增用例使用 `IMP-Ixx-序号`，不覆盖既有测试编号。

每个功能至少记录：正常路径、权限失败、边界条件、重复/并发请求（适用时）、重启恢复（适用时）及界面反馈。记录模板如下：

| 字段 | 内容要求 |
| --- | --- |
| 编号与功能 | 例如 IMP-I01-01：修改密码后撤销旧会话 |
| 前置条件 | 数据集、账号、配额、服务配置及版本 |
| 操作与输入 | 可复现步骤，不写入真实密码/令牌 |
| 预期结果 | 状态码、页面文字、数据/文件变化、应保持不变的状态 |
| 实际结果 | 真实观察到的响应、数量、摘要及错误 |
| 状态 | 待实施 / 实施中 / 待验证 / 通过 / 失败 / 待环境 |
| 证据 | 测试输出、脱敏响应、截图或恢复报告的路径 |
| 问题闭环 | 原因、修复、复测记录、尚存限制 |
