# CloudNest 1.0.0

首个正式稳定版本，支持单个后端实例部署的私人云盘。

## 稳定范围

- 个人文件管理、分片上传与续传、内容校验、历史版本、分享和回收站。
- 团队成员与目录权限、团队配额、邀请与撤权。
- 目录快照与副本恢复、本地和 S3 兼容存储、节点管理与数据保护任务。
- 账号会话、TOTP、WebDAV 应用密码及可选邮件找回。

Windows 同步客户端、公网直传及有界 AI Agent 仍按实验能力提供，不属于本次稳定性承诺。多业务实例、零知识加密和原生虚拟盘不在支持范围内。具体限制见功能说明。

## 发布与升级

- 宿主机更新器默认使用 stable 通道，仅选择 GitHub latest 正式 Release；preview 通道显式选择后才跟随 main。
- 正式包包含 Linux amd64 前后端镜像及 SHA256SUMS；按提交编号保留相同镜像供更新器使用。
- 只有后端验证、MySQL 迁移验证、前端构建、浏览器回归、部署工具及 Docker 隔离恢复检查通过后，工作流才发布正式 Release。
- 从开发版升级前，备份数据库、对象、配置和密钥。新版迁移后不能仅切回旧镜像；恢复需要同批完整备份。
- 本次发布没有新增数据库迁移。旧开发版可能尚未执行仓库中的既有迁移，仍需按部署手册停写备份。
- 已领先正式版本的开发部署不会被自动降级；等待下一正式版本，或继续使用 preview 通道。

## 验证边界

自动化检查不等同于生产 SLA。真实 S3 服务的 CORS/签名兼容性、跨物理机器故障、容量上限和长期负载需要按部署环境验证。快照与双副本不能替代独立备份。

安装与恢复见 `docs/deployment.md`；更新通道配置见 `docs/system-updates.md`。

## 版本编号更正

本项目首个稳定版的正式编号为 **1.0.0**。此前发布的 `v2.3.0` 属于编号错误，已由本版本取代。此次更正不增加业务功能或数据库迁移；从该错误编号版本更新到 1.0.0 是提交历史上的前进更新，不需要回退或清空数据。
