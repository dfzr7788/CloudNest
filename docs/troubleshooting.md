# 故障排查

[文档中心](README.md) · [配置参考](configuration.md) · [部署与恢复](deployment.md)

先确定故障发生在浏览器、Web 入口、后端、数据库还是存储。保留错误时间和操作，不通过清空数据卷、替换密钥或删除迁移记录来试错。

## 无法访问或登录

在服务器项目目录运行：

```bash
docker compose ps
curl --noproxy '*' -I http://127.0.0.1:8088/
curl --noproxy '*' -f http://127.0.0.1:8088/api/auth/csrf
docker compose logs --tail=100 server web
```

使用自定义端口时替换 8088。

| 现象 | 检查方向 |
| --- | --- |
| 本机正常，外部不通 | 安全组、防火墙、实际端口映射；基础 Compose 只绑定回环，公网叠加才绑定全部接口 |
| 首页正常，API 失败 | server 健康状态、数据库启动、Web 代理日志 |
| 登录后立即回到登录页 | HTTP 与 `SECURE_COOKIES` 是否一致、浏览器是否保存 Cookie、代理是否改变地址 |
| 密码错误 | 网站密码与数据库密码不同；没有内置 admin 密码；按部署手册重置 |
| 没有注册入口 | Docker 默认关闭公开注册，由管理员发邀请 |
| HTTPS 页面部分资源失败 | 浏览器混合内容错误、Office 或公开存储地址是否仍为 HTTP |

## 启动、构建与迁移

- 健康等待超时：检查 MySQL/server 日志、可用内存与磁盘，修复原因后重新 `up`。
- Maven/npm 下载失败：确认失败阶段及网络；不删除数据库卷来处理依赖下载。
- 预构建镜像缺失：确认架构和提交是否已有发布产物；镜像部署等待对应发布，源码部署按源码流程构建。
- Flyway 校验失败：核对程序版本与数据库来源，不编辑已执行迁移或删除历史记录；通过新迁移或完整恢复处理。
- 修改 `.env` 无效：检查 Compose 是否转发变量、是否重新创建容器、是否被持久化网页设置覆盖。

## 上传、下载与空间

| 现象 | 下一步 |
| --- | --- |
| 上传刷新后要求重选 | 浏览器未保留原文件缓存；选择同一文件并通过摘要核验 |
| 413 / 上传体积错误 | 检查外层代理、WebDAV 整文件请求和单文件上限；分片上限不等于文件上限 |
| 配额不足但磁盘有空间 | 个人/团队逻辑配额包含历史、回收站和快照引用，查看空间分项 |
| 删除后磁盘未立即释放 | 还有版本/快照/分享引用，或后台物理清理尚未执行 |
| ZIP 失败或过期 | 检查数量、512 MiB 默认总大小限制、磁盘、权限及源文件变化；重新创建任务 |
| S3 直连失败而代理可用 | 检查公开地址、CORS、Range 和签名兼容性；不要据此认定对象丢失 |
| 无有效副本 | 查看巡检与节点状态；`NO_VALID_REPLICA` 不能靠反复重试制造可恢复内容，需独立备份 |

## 团队、预览与邮件

- 团队操作被拒绝：核对成员角色与目录 ACL；子目录授权不能扩大父级权限，撤权也影响在途上传。
- Office 阅读排版不同：内置预览仅提取文字和基本表格；需要编辑时配置 OnlyOffice。
- PDF 无正文搜索：扫描图片 PDF 没有文本层，当前不提供 OCR；新文件索引也可能仍在后台生成。
- 邮件未收到：先由管理员测试 SMTP，核对地址、垃圾邮件和服务器日志；找回接口不会透露账号是否存在。
- TOTP 丢失：先用一次性恢复码；全部丢失时按[进阶配置](advanced-features.md#webdav双重验证和邮件找回)由维护人员处理。邮件找回不会移除 TOTP。

## AI 与更新任务

AI 不可用时依次检查站点开关、个人连接、模型用途和网络策略；目前模型端点只接受通过地址策略的公网 HTTPS 443。不要把内网模型连接失败当成密钥错误。超时、取消或服务重启后，上游仍可能计费；先看任务记录，不自动重复付费请求。

更新失败按网页显示的阶段检查宿主机日志，见[系统更新排障](system-updates.md#备份与排障)。应用容器更新不等于宿主机 worker 已更新，辅助模块也需要匹配。备份失败后服务恢复不代表备份成功。

## 报告问题

提供版本/提交、部署方式、浏览器与系统、发生时间、最短复现步骤、预期和实际结果。只附脱敏日志，删除 Cookie、密码、API Key、完整分享/邀请链接和私人内容。安全漏洞按[安全反馈](../SECURITY.md)私下提交。
