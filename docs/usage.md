# 使用说明

本手册按当前界面介绍日常操作。服务器安装见 [部署手册](deployment.md)，可选服务见 [进阶配置](advanced-features.md)，模型配置和调用见 [AI 使用说明](ai.md)。本文容量和数量为默认限制；管理员可调整的项以实际部署为准。

## 第一次使用：完成一次文件闭环

1. 使用管理员提供的账号或邀请链接登录；没有默认密码。先打开“账号与安全”确认账号与剩余空间。
2. 在“我的文件”新建一个测试文件夹，上传文本或图片；打开预览，再下载确认内容一致。
3. 为测试文件创建短期分享，在未登录窗口打开，验证提取码与下载设置。测试后在“我的分享”撤销。
4. 删除测试文件，在回收站恢复。需要保留某次目录状态时，再学习目录快照。
5. 需要团队协作、客户端或 AI 时，再按下面对应章节配置。这些并不是普通上传下载的前置条件。

## 登录与导航

使用管理员创建的账号或邀请链接注册，没有默认 admin 密码。Docker 默认关闭公开注册；本地开发默认开放。邀请一次有效，48 小时过期，完整链接只在创建时显示。

侧栏包含“我的文件”“我的收藏”“最近使用”“最近上传”“我的分享”“回收站”“团队空间”和“数据保护”，管理员还可进入“节点中心”。手机通过顶栏导航按钮展开侧栏。“账号与安全”在桌面以左侧分组切换，手机使用分组选择。

文件区的“全部文件”表示当前目录。顶栏名称搜索可选全部目录或当前目录；类型、大小、修改时间在“筛选”中设置，条件标签可单独移除。“标签与正文搜索”是独立入口，正文索引可能尚在生成，不等同于 AI 语义搜索。

## 文件操作与跨目录选择

点击文件名预览、点击文件夹名进入目录。列表和网格均可选择项目；选中后出现批量操作栏，可分享、复制、剪切、移动、删除，或打开“查看已选”检查完整路径。

选择可跨目录、搜索结果和分页保留，最多 100 个入口。“全选当前页”和取消当前页只影响当前页，保留其他目录已选项；切换文件、分享和回收站分区会清空选择。复制或剪切后进入目标目录粘贴，取消选择不清除已复制的项目。Ctrl/Cmd+A、C、X、V 在文件区生效，输入框和弹窗内保留原有输入行为。

文件更多菜单提供重命名、收藏、标签、历史版本和分享等操作。目录不能移入自身或后代；重名和过期修订会给出冲突提示。复制保留当前内容、目录结构和标签，不复制历史版本或分享链接；每份副本分别占用逻辑配额。

## 上传与恢复

点击“上传文件”；旁边的“更多上传选项”提供文件夹上传，以及“覆盖并保留历史”“保留两份”“跳过”同名策略。文件夹上传保留相对路径，每次最多 2000 个文件、32 层；浏览器不提供的空文件夹无法上传。默认单文件最大 2 GiB。

上传面板分别显示本地 SHA-256 校验和网络上传进度，可暂停、继续、取消及收起；收起不会取消任务。系统使用分片和同用户内容校验，配额不足或校验失败会显示具体原因。

浏览器会尝试缓存上传队列和文件内容。刷新或重开页面后，缓存完整的任务可以恢复，暂停的任务仍保持暂停；原文件缓存被清理时，需重新选择同一原文件并通过大小和摘要核验。未完成的服务器会话默认保留 24 小时。

## 下载与 ZIP 任务

单个文件使用行内下载按钮或更多菜单。文件夹选择“压缩下载”；多选后使用“打包下载”，可跨目录选取文件与文件夹。在下载任务区查看进度、取消或重新创建失败任务，完成后下载 ZIP；刷新页面仍可查询尚未过期的任务。

文件夹递归包含后代及空目录，父目录与子项同时选择会去重。默认一次最多选择 100 个入口，展开后最多 1000 个文件、2000 个文件与目录、64 层，文件总大小不超过 512 MiB。超过限制请分批下载。

ZIP 默认保留 1 小时。任务是创建时的快照，新加入文件不会自动进入旧包；源内容、版本、位置或权限变化后任务可能失效，需要重新打包。系统会处理不兼容文件名和 ZIP 内重名。

## 预览与历史版本

| 类型 | 阅读能力与限制 |
| --- | --- |
| 图片 | 适配窗口、缩放、旋转和前后切换 |
| PDF | 本地 PDF 渲染组件，支持 HTTP IP 访问；加密或损坏文件可能无法读取 |
| 文本 / Markdown | 最大 2 MiB；Markdown 支持数学公式、代码高亮、表格和权限范围内的相对附件；不自动加载远程图片 |
| DOC/DOCX、XLS/XLSX、PPT/PPTX | 最大 10 MiB，提供文本与基本表格阅读；复杂排版、图片、宏、动画和公式重算以原件为准 |
| 音视频 | 使用浏览器原生播放，同时受服务端 MIME 白名单和浏览器编码支持限制；不提供服务端转码 |

HTML、SVG 等内容不作为可执行网页预览。可选 OnlyOffice 由管理员配置后，为拥有者提供 Office 查看/编辑入口，公开分享访客不能编辑。

文件更多菜单中的“历史版本”可下载、恢复或清理旧内容，最多保留 20 个历史版本。覆盖同名文件并保留历史时，条目不变，旧内容进入历史并占用配额。

开启 AI 后，自己的 TXT、Markdown、带文本层 PDF 和 DOCX 预览中可打开“AI 阅读助手”。桌面并排显示文档与助手，窄屏切换后可“返回文档”继续阅读。公开分享没有 AI 入口。具体支持范围和确认流程见 [AI 使用说明](ai.md)。

## 分享与文件收集

创建文件或目录分享时设置有效期、提取码和下载权限，然后复制完整链接。“我的分享”可按状态筛选，调整仍有效的分享、查看统计或撤销。提取码可留空，否则为 4～32 字符且 UTF-8 不超过 72 字节；有效期为 1～720 小时。修改设置会使已有提取码授权失效。

单文件分享固定创建时的内容版本；目录分享展示当前有效的目录后代。多选后可创建集合分享，仅公开选中项目及其目录后代。统计中的访问和下载数是请求计数，不是独立访客或完整下载次数。

访客打开链接后按需输入提取码，可在授权范围内浏览和预览；允许下载时可下载单文件、整个文件夹，或跨目录勾选后打包。禁止下载时不显示下载操作，预览仍受分享范围约束。撤销、过期或来源失效后，旧 ZIP 任务也不能继续下载。

文件夹更多菜单中的“收集文件”创建只上传链接。访客看不到已有文件或他人上传内容；每个链接最多收集 100 个文件，每个最多 100 MiB，受拥有者配额和分享有效期约束。

## 回收站与空间

普通删除进入回收站，并提供短暂撤销入口。回收站可以恢复或彻底删除，永久删除需要确认。默认用户配额 5 GiB，当前文件、回收站、历史版本和快照引用均计入逻辑占用；团队配额从所有者可用空间划拨，上传预留单独显示。彻底删除和清理历史会释放对应逻辑配额，底层物理清理由后台完成，两者可能不同步。

“账号与安全 → 空间与回收站”查看各部分占用并配置自动清理：0 表示关闭，其他为 1～365 天，由后台周期执行。已超过保留期的内容可能在后续清理时永久删除。

## 账号与安全

| 分组 | 面板与用途 |
| --- | --- |
| 安全 | 修改密码、客户端与同步、登录会话：邮箱、TOTP、WebDAV 应用密码、会话撤销 |
| 空间与记录 | 空间与回收站、活动记录 |
| AI | AI 设置、AI 知识库、智能整理；是否可用由站点开关控制 |
| 管理员 | 系统管理、集成服务、系统更新，仅管理员可见 |

昵称从侧栏个人资料入口修改。修改密码后需重新登录；可单独撤销自己的其他登录会话。启用 TOTP 时保存十个一次性恢复码；WebDAV 使用专用应用密码。邮件验证与找回需要管理员先配置 SMTP，邮件重置不会移除 TOTP。详细流程见 [进阶配置](advanced-features.md#webdav双重验证和邮件找回)。

管理员在“系统管理”创建邀请、调整配额或禁用普通账号；“集成服务”配置邮件和 Office；节点中心统一管理存储连接、默认策略、容量告警和迁移任务；“系统更新”需要先安装宿主机配套服务。维护及恢复步骤见 [部署手册](deployment.md) 和 [系统更新](system-updates.md)。

## 团队空间与数据保护

进入“团队空间”创建或选择团队。创建时填写名称并从个人可用配额划拨空间；成员按角色及目录权限操作文件。“成员与权限”提供一次性邀请、邀请历史与撤销、角色修改及目录 ACL。邀请令牌只在创建时展示，未保存时需撤销并重建。团队管理员可管理快照和恢复，以及提交迁移或副本任务。

进入“数据保护”选择目录并创建快照，查看历史树和相对当前状态的变化。找不到已删除目录时，启用“显示所有历史目录”。先预览再恢复单文件或子树，恢复内容以副本写入当前所选目标目录。取消任务保留已经恢复的文件；快照与恢复副本都计入配额。

管理员可配置巡检和限速，并在节点中心查看节点健康、容量、迁移及副本保护结果。详细角色、配额和任务边界见[功能说明](features.md)。

## 四种“恢复”如何选择

| 场景 | 使用方式 | 结果 |
| --- | --- | --- |
| 刚删除文件 | 撤销或回收站恢复 | 恢复被删除的条目 |
| 同名覆盖后找旧内容 | 文件历史版本 | 恢复指定历史内容；先核对版本 |
| 找回某次目录状态 | 数据保护中的快照恢复 | 向目标目录写入副本，不覆盖当前文件 |
| 服务器、数据库或整套存储损坏 | 管理员恢复独立备份 | 恢复配套数据库、对象、密钥及运行版本 |

前三种依赖现有系统及内容对象仍然可用。重要资料应由管理员安排独立备份。操作出现异常时先保留界面错误信息，按[排障手册](troubleshooting.md)处理。
