# 使用说明

## 账号与邀请

部署后用维护脚本创建的账号和密码登录，没有默认 admin 密码。默认关闭公开注册；管理员在“账号与安全 → 系统管理”创建邀请，复制完整链接发送给对方。邀请一次有效，48 小时过期，链接只在创建时显示。管理员可以设置用户配额和禁用普通账号；禁用会撤销登录会话。

在“账号与安全”可修改自己的密码、查看和撤销登录会话、查看空间占用以及设置回收站保留时间。回收站自动清理设置为 0 时关闭，其他可选值为 1～365 天。

## 上传与整理

点击“上传文件”或“上传文件夹”。文件夹上传保留相对目录结构，浏览器不提供的空文件夹无法上传。每次目录上传最多 2000 个文件、32 层目录。单文件上限为 2 GiB；界面使用分片和内容摘要校验，页面重开后需重新选择相同原文件才能续传。同名处理可选择跳过、保留两份或覆盖并保留历史。

可以新建文件夹、重命名、移动、收藏和搜索文件，也可以勾选后批量移动或删除。移动目录不能形成循环。图片、文档、大小和时间筛选按当前选择的搜索范围生效。

普通删除进入回收站，仍占用配额；彻底删除和清理历史版本才会释放相应逻辑空间。默认用户配额 5 GiB，管理员可以调整。

## 下载与压缩下载

单个文件点击行内下载图标，或在更多菜单中选择下载。文件夹使用“压缩下载”；多选文件或文件夹后，点击“打包下载”。进入其他目录、搜索或翻页后仍保留已选项，可在“查看已选”中核对完整路径或移除项目；“全选当前页”只作用于当前页，不取消其他目录的选择。打包完成后点击下载 ZIP。任务列表可查看进度，页面刷新后仍可查看尚未过期的任务。

文件夹会递归包含全部后代及空目录；同一文件夹与其子项同时选中会去重。一次最多选择 100 个入口，展开后最多 1000 个文件、2000 个文件与目录，文件总大小不超过 512 MiB、目录深度不超过 64 层。超过限制时请分批下载。

压缩任务有效期为 1 小时。源文件内容、版本或目录位置等发生变化后，旧任务可能失效，需要重新打包；任务创建后新加入的文件不会自动进入旧压缩包。压缩包会处理不兼容的文件名并避免覆盖重名内容。

## 预览与历史版本

支持常见图片、PDF、文本、Markdown、DOC/DOCX、Excel/PPT 阅读预览，以及浏览器支持的音视频格式。Markdown 提供标题、列表、表格、代码块等渲染与源码切换，并清理可执行 HTML；不加载文档中的远程图片。Word 提供文本阅读预览，DOCX 保留标题、加粗、斜体和表格；复杂版式、图片与批注以下载原件为准，Word 上限 10 MiB，损坏或加密文档会给出提示。文本及 Markdown 预览最多 2 MiB；音视频能否播放取决于浏览器编码支持，不进行服务端转码。HTML/SVG 等内容不作为可执行网页预览。

文件更多菜单可管理历史版本、下载旧版本或恢复所选内容。每个文件最多保留 20 个历史版本，历史内容也占用配额。

## 分享

通过分享按钮创建文件或目录分享，设置有效期、提取码和是否允许下载，然后复制完整链接给对方。“我的分享”可以调整设置或撤销分享。

目录分享只允许访问共享目录的后代；允许下载时，可以点击“下载整个文件夹”，勾选文件夹递归打包，或进入多个目录挑选部分文件后“打包选中项目”。分享页同样保留跨目录选择，且支持 PDF、Word 和 Markdown 预览。分享撤销、过期或来源不再有效后，原下载任务也不能继续使用。固定文件分享与当前文件版本的行为以分享创建时选项为准。

## 更新与部署

管理员的“账号与安全 → 系统更新”提供检查更新和一键更新。需要服务器先安装更新服务，详见 [系统更新](system-updates.md)。初次安装、IP 加端口访问、备份、密码重置和排障见 [部署手册](deployment.md)。

复制粘贴、数学公式和附件、Office 编辑、集合分享与收集、WebDAV、邮箱找回和双重验证、存储策略与标签正文检索，见 [进阶功能与配置](advanced-features.md)。ZIP 数量与保留期可由管理员配置，本文数字为默认值。
# AI 阅读助手

DeepSeek 官方连接可填写根地址 `https://api.deepseek.com`、模型 ID `deepseek-flash` 或 `deepseek-v4-pro`、输出参数 `max_tokens`。每个模型配置只填一个 ID。当前摘要、标签和连接测试会对这些官方模型显式关闭思考模式，保证有限输出预算用于最终答案；第三方兼容地址不会自动发送这一厂商参数。连接测试最多输出 256 token，同时受模型自身输出上限约束。若供应商因输出上限中断生成，任务返回 `AI_OUTPUT_LIMIT`，不把截断文本当作完整结果，也不自动重发；供应商已返回的实际用量仍记录。

站点默认关闭 AI。管理员开启后，进入“账号与安全 → AI 设置”：

1. 添加自己的 API 连接，填写显示名、包含版本路径的 HTTPS 公网根地址和 Key。例如 `https://provider.example/v1`，不要填写完整 `/chat/completions` 地址。
2. 添加聊天模型，手动填写供应商的模型 ID、上下文窗口、最大输出与 `max_tokens` / `max_completion_tokens` 兼容模式。保存配置不会产生请求。
3. 查看并确认该目的地的数据发送和费用说明。服务器调用时能解密 Key，运维者有技术访问能力；浏览器不持久保存 Key。目的地改变必须重新输入 Key 并重新同意。
4. 可显式测试模型，只发送固定短提示，可能收费。成功只代表本次聊天调用成功。
5. 打开自己的 TXT、Markdown、带文本层 PDF 或 DOCX，在预览中选择“AI 阅读助手”。先检查范围（不调用收费模型），查看修订、页数、字符数与预计调用次数，再确认生成摘要或建议标签。

文本须为 UTF-8，最大 2 MiB；PDF/DOCX 最大 10 MiB。提取最多 100 页/262144 字符；扫描件无 OCR。DOCX 按正文段落与表格行提取，页眉页脚、图片文字、批注、文本框不在范围内；不伪造 Word 分页。可缩小从开头起的分析字符数；部分内容必须明确勾选同意，结果持续标示范围。长文分段摘要后合并，单任务最多 8 次调用，每次输入最多 24000 字符。未知模型按 UTF-8 字节数保守估计上下文，实际仍受供应商限制。

标签最多建议 8 个，选择后展示与当前标签的合并结果，确认才保存；总计最多 20 个、每个 40 字符。并发修改会拒绝保存并提示重新确认。

离开面板不会取消任务，返回后可从任务列表恢复查看。停止会中断正在运行的请求，但无法收回已发送数据，也不保证停止计费。超时、网络错误和服务重启均不自动重发收费请求。每日最多 100 次调用（包含测试和每个分段），UTC 00:00/北京时间 08:00 重置。“使用记录”中未返回的实际 token 显示未知，不代表零费用。

相同文件修订、模型配置、目的地、范围和语言可复用最近 7 天的结果；“重新生成”会再次调用。任务和缓存保留 7 天，用量保留 90 天，幂等记录保留 24 小时。可删除 AI 结果，源文件不受影响。文件回收、父目录回收或修订变化后立即拒绝旧结果访问；永久删除的文件派生结果由后台补偿清理。

首版不支持单文档问答、向量搜索、知识库、OCR、图像理解或自动整理；公开分享、收集链接、WebDAV 无 AI 入口。只接受公网 HTTPS 443，暂不支持自定义额外端口和本地模型别名；服务器 localhost 是服务器自身。
