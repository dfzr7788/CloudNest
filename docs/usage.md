# 使用说明

## 账号与邀请

部署后用维护脚本创建的账号和密码登录，没有默认 admin 密码。默认关闭公开注册；管理员在“账号与安全 → 系统管理”创建邀请，复制完整链接发送给对方。邀请一次有效，48 小时过期，链接只在创建时显示。管理员可以设置用户配额和禁用普通账号；禁用会撤销登录会话。

在“账号与安全”可修改自己的密码、查看和撤销登录会话、查看空间占用以及设置回收站保留时间。回收站自动清理设置为 0 时关闭，其他可选值为 1～365 天。

## 上传与整理

点击“上传文件”或“上传文件夹”。文件夹上传保留相对目录结构，浏览器不提供的空文件夹无法上传。每次目录上传最多 2000 个文件、32 层目录。单文件上限为 2 GiB；界面使用分片和内容摘要校验，页面重开后需重新选择相同原文件才能续传。同名处理可选择跳过或保留两份。

可以新建文件夹、重命名、移动、收藏和搜索文件，也可以勾选后批量移动或删除。移动目录不能形成循环。图片、文档、大小和时间筛选按当前选择的搜索范围生效。

普通删除进入回收站，仍占用配额；彻底删除和清理历史版本才会释放相应逻辑空间。默认用户配额 5 GiB，管理员可以调整。

## 下载与压缩下载

单个文件点击行内下载图标，或在更多菜单中选择下载。文件夹使用“压缩下载”；多选文件或文件夹后，在批量操作栏选择“压缩下载”。打包完成后点击下载 ZIP。任务列表可查看进度，页面刷新后仍可查看尚未过期的任务。

文件夹会递归包含全部后代及空目录；同一文件夹与其子项同时选中会去重。一次最多选择 100 个入口，展开后最多 1000 个文件、2000 个文件与目录，文件总大小不超过 512 MiB、目录深度不超过 64 层。超过限制时请分批下载。

压缩任务有效期为 1 小时。源文件内容、版本或目录位置等发生变化后，旧任务可能失效，需要重新打包；任务创建后新加入的文件不会自动进入旧压缩包。压缩包会处理不兼容的文件名并避免覆盖重名内容。

## 预览与历史版本

支持常见图片、PDF、文本，以及浏览器支持的音视频格式。文本预览最多 2 MiB；音视频能否播放取决于浏览器编码支持，不进行服务端转码。HTML/SVG 等内容不作为可执行网页预览。

文件更多菜单可管理历史版本、下载旧版本或恢复所选内容。每个文件最多保留 20 个历史版本，历史内容也占用配额。

## 分享

通过分享按钮创建文件或目录分享，设置有效期、提取码和是否允许下载，然后复制完整链接给对方。“我的分享”可以调整设置或撤销分享。

目录分享只允许访问共享目录的后代；允许下载时可递归压缩下载。分享撤销、过期或来源不再有效后，原下载任务也不能继续使用。固定文件分享与当前文件版本的行为以分享创建时选项为准。

## 更新与部署

管理员的“账号与安全 → 系统更新”提供检查更新和一键更新。需要服务器先安装更新服务，详见 [系统更新](system-updates.md)。初次安装、IP 加端口访问、备份、密码重置和排障见 [部署手册](deployment.md)。
